### 发现的问题（从工作日志分析）

| 问题 | 错误信息 | 根因 | 解决方案 |
|:---|:---|:---|:---|
| Git Bash fork 错误 | `do fork: child -1 - forked process died, exit code 0xC0000142` | Windows 资源不足 | 使用 PowerShell ProcessStartInfo 或 Python subprocess |

| Nginx 静态文件 403 | 403 Forbidden | 权限配置问题 | 改为 CSS/SVG 内联 |

### 关键技术点

1. **避免 Git Bash fork 错误**：
   - 不要用 Bash 工具执行 git 命令
   - 改用：`& "C:\Program Files\Git\bin\git.exe" ...`
   - 或 Python：`subprocess.run([git, ...])`
   - 或 PowerShell：`ProcessStartInfo` 方式

2. **SFTP 直接上传**（绕过 GitHub push 失败）：
   ```python
   import paramiko
   ssh = paramiko.SSHClient()
   ssh.connect(host, username=username, key_filename=key_path)
   sftp = ssh.open_sftp()
   sftp.put(local_path, remote_path)
   ```

3. **CSS/SVG 内联**（绕过 Nginx 403 问题）：
   - 不要在 HTML 中引用 static/*.png
   - 改用 `<svg>...</svg>` 或 `<div style="...">`
   - 彻底摆脱静态文件依赖

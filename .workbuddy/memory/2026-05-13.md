## 出版社排版流水线搭建 + 5篇论文终版导出

### 问题背景
用户对格式不满意，要求出版社编辑级排版：A4打印状态、宋体正文、黑体标题、脚注每页底部显示。

### 解决方案
建立完整排版流水线：
1. 创建参考模板 `_reference_template.docx`（python-docx）：A4/宋体五号/黑体标题/脚注样式
2. pandoc `--reference-doc` 应用模板导出
3. 脚注转换：著者-年份智能匹配 → `[^refN]` 标记 → pandoc页底脚注

### 排版规格
- A4 (210×297mm)，页边距上下2.54cm/左右2.8cm
- 正文：宋体五号(10.5pt)，1.5倍行距，首行缩进2字符
- 标题：黑体三号(16pt)/四号(14pt)/小四(12pt)
- 脚注：小五号(9pt)
- 表格：深蓝表头(#1F4E79)白字+交替浅蓝行色

### 关于GLM的评估

- 可行方案：Flask后端不变 + 新增交互组件时用GLM辅助生成HTML → 人工审核嵌入模板体系
- 不可行方案：用GLM重写整个网站 → 丢掉6个月积累 → 风险极大

项目定位

本项目受 nju-thesis-markdown（南京大学 Markdown 论文排版工具）启发，从零独立开发面向武汉大学研究生的论文排版流水线。与 nju-thesis-markdown 不同，本项目不仅解决"排版"问题，还独创性地加入了论文健康度检查和格式诊断引擎，让论文在排版前就能发现结构性问题。

开发者说："OGD-Collector Pro 的论文工坊在检查论文健康度时，我发现手动核对脚注连续性、图片缺失、中英文比例非常繁琐。于是我把这套检查逻辑提炼成了一个独立的 Python 包，让任何武大学生都能一键检查自己的论文。排版只是最后一步，先确保论文结构健康才是核心。"

核心功能
1
双引擎转换
Pandoc 通用路线 + python-docx 精细控制路线，兼顾效率与精度
2
论文健康度检查
8维度完整性诊断：章节结构、图表、脚注、引用、图片、中英文比例、字数、格式
3
格式规则引擎
YAML 配置化，支持多学校模板扩展，武大格式一键应用
4
Web 界面
在线检查 + 一键导出 + 实时预览，无需安装即可使用（集成在 OGD-Collector 论文工坊）
5
Lua Filter
Pandoc 转换过程中的自定义处理，中文字体映射、脚注格式调整
6
数据联动
与 OGD-Collector Pro 论文系统联动，采集数据直接反哺论文实证章节
快速开始
bash pip install whu-thesis-pipeline
bash # 健康度检查 whu-thesis-check docs/thesis.md # 生成 DOCX（python-docx 引擎） whu-thesis-convert docs/thesis.md --engine=docx --output=output/ # 完整流水线：检查 → 转换 → 诊断 whu-thesis-pipeline docs/thesis.md --config=config/whu_phd.yaml
python from whu_thesis import ThesisPipeline pipeline = ThesisPipeline(config="config/whu_phd.yaml") # 健康度检查 health = pipeline.check_health("docs/thesis.md") print(f"健康度: {health.score}/100") # 转换 pipeline.convert("docs/thesis.md", output="output/thesis.docx")
武汉大学格式支持清单
✓ 封面页（分类号/UDC/编号/题目/作者/导师/学科）
✓ 原创性声明 + 使用授权协议
✓ 创新点页
✓ 中英文摘要
✓ 自动目录（TOC 域）
✓ 图目录 + 表目录
✓ 正文（黑体标题 + 宋体正文 + 1.5倍行距 + 首行缩进2字符）
✓ 图片嵌入 + 表格渲染（三线表样式）
✓ 参考文献（悬挂缩进）
✓ 致谢
○ 脚注圈码①②③（需 WPS/Word 精修）
○ 页眉页脚（需 WPS/Word 精修）
